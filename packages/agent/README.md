# Nirium Institutional Agent

This package contains the proprietary execution logic for the Nirium Network. It is a private component and its source code is not included in the public repository.

## Why is this private?
Nirium is an institutional-grade treasury protocol. While the **Smart Contracts** (on-chain logic) and **SDKs** (integration layer) are open-source for trust and auditability, the **Autonomous Execution Engine** represents our core Intellectual Property.

## How to use?
To interact with the Nirium Network, please use the provided SDKs:
- [nirium (TypeScript)](https://www.npmjs.com/package/nirium)
- [nirium (Python)](https://pypi.org/project/nirium/)

If you are an Institutional Partner, you have received a private API key to access our hosted execution clusters.

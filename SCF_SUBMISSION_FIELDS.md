## 6. Solution (Including Stellar's Role)

```
Nirium eliminates the human bottleneck from the profitability curve without sacrificing self-custody or decentralization. Stellar is not decorative — it IS the execution layer.

Here's how it works:

1. Continuous Detection: An asynchronous Node.js agent continuously reads Stellar network state via Horizon API and Soroban RPC, scanning for price anomalies, cross-venue inefficiencies (SDEX vs Soroswap), and yield opportunities (Blend pools).

2. AI Synthesis: Market data passes through a configurable LLM matrix (from local Ollama instances to GPT-4o, Gemini, Claude, Grok) that evaluates whether a validated opportunity exists and structures the execution payload.

3. Atomic Execution via Soroban: If profitability is confirmed, the agent invokes a Soroban smart contract (NiriumVault) to execute a flash_loan — borrowing, swapping, and repaying within a single atomic transaction. If the simulation shows a loss, Soroban reverts the entire transaction, protecting all funds. Zero risk of partial execution.

4. Settlement & Audit: On success, the contract retains the loan repayment and deducts a protocol fee. 99% of profit is returned to the user, with a portion redistributed to stakers. The complete decision logic (the "Blackbox") is permanently indexed with an **IPFS CID** for forensic-grade immutable auditing via Pinata. The agent's on-chain ELO score is updated in real-time on the ELO Registry contract.

Why Stellar specifically:
- Sub-second finality enables real-time arbitrage execution
- Base fees of ~100 stroops ($0.000001) make high-frequency strategies economically viable
- Native SDEX orderbook provides built-in liquidity without external DEX dependencies
- Soroban smart contracts enable atomic flash loans with automatic reversion on loss
- Path payment operations enable multi-hop atomic swaps across asset pairs
- Established anchor ecosystem (USDC, EURC) provides institutional-grade stablecoin rails
```

¿Cómo es seguro darle dinero a una IA?

  • La IA nunca tiene custodia. Solo propone.
  • Un contrato multifirma (2 de 3) revisa y aprueba cada movimiento on-chain.
  • Si la IA se equivoca o la hackean, simplemente no puede mover fondos que el contrato no autorizó.
  • Hacerlo funcionar 24/7 nos costó sudor de verdad. Esto está en producción, no es un demo de hackathon.

Lo que ya funciona — x402 en vivo

Una app paga por lo que usa. Automático, on-chain, sin humano.

import { Agent } from "nirium";

const agent = new Agent({ baseUrl: "https://nirium-agent.fly.dev" });

agent.initX402({ secretKey: process.env.STELLAR_SECRET_KEY, network: "stellar:testnet" });

// Un request = un pago on-chain. El SDK firma el auth entry y paga solo.
const res = await agent.x402Fetch("https://nirium-agent.fly.dev/api/v1/premium/signals");

NIRIUM PLAY — Logo Pack
========================

Variante del mark de Nirium para el sub-brand "Play" (juegos/demos on-chain):
silueta de control de videojuegos + la N oficial de Nirium + un acento de
Stellar. No trae wordmark ni lockup todavía — solo el ícono, en dos
variantes.

Qué usar en cada caso:

REDES SOCIALES / AVATAR
  png/avatar-dark-800.png o avatar-dark-1600.png   -> fondo oscuro (#0A0A0C)
  png/avatar-light-800.png o avatar-light-1600.png -> fondo claro (#F5F3EF)
  Usa el de 1600 si la plataforma pide alta resolución.

FAVICON DEL SITIO WEB (el ícono de la pestaña del navegador)
  png/favicon-16.png, favicon-32.png, favicon-48.png, favicon-180.png, favicon-512.png
  Fondo transparente. Es una silueta simplificada y rellena a propósito —
  el ícono hero (con el trazo delgado y los gatillos L/R) deja de leerse
  por debajo de ~48px, así que el favicon usa un dibujo distinto, más
  grueso, probado con captura real hasta 16px.

SOLO EL ÍCONO (hero, con el detalle completo), fondo transparente
  png/icon-transparent-512.png, -1024.png, -2048.png
  Para ponerlo sobre cualquier color de fondo. Usa el de mayor resolución
  si vas a imprimir o agrandar.

VECTORIAL (SVG) — para diseñadores o desarrolladores
  svg/icon.svg      -> ícono hero, a color, con el detalle completo
  svg/favicon.svg   -> versión simplificada y rellena, para tamaños chicos
  Un SVG se puede agrandar a cualquier tamaño sin perder calidad.

NOTAS IMPORTANTES
  - No hay wordmark ("NIRIUM PLAY" en texto) ni lockup todavía — si hace
    falta, es un encargo aparte, no algo que este pack ya resuelva.
  - No hay variantes mono (un solo color, para imprenta) todavía.
  - No se corrió una búsqueda formal de marca registrada contra este
    ícono — es una variante interna para HackMeridian, no un mark que se
    vaya a registrar.
  - No se probó contra el ancho real de ningún navbar.
  - La N que usa es un path idéntico al de branding-nirium/svg/icon.svg
    (verificado byte a byte contra la copia real en producción de
    nirium.xyz/branding-nirium antes de publicar esto).
  - Color: mismo degradado dorado que la marca principal
    (#F5D57A -> #D4AF37 -> #8B6F2E). No reemplazar por un dorado plano.

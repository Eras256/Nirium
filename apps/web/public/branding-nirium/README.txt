NIRIUM — Brand Assets Pack
===========================

Qué usar en cada caso (sin necesitar conocimiento técnico):

REDES SOCIALES / AVATAR
  png/avatar-800.png o avatar-1600.png
  Fondo negro sólido, listo para subir directo a Twitter/X, Discord, LinkedIn, Telegram.
  Usa el de 1600 si la plataforma pide alta resolución.

FAVICON DEL SITIO WEB (el ícono de la pestaña del navegador)
  png/favicon-16.png, favicon-32.png, favicon-48.png, favicon-180.png, favicon-512.png
  Fondo transparente. El desarrollador sabe cuál va en cada campo del sitio
  (16/32 = pestaña del navegador, 180 = ícono al agregar el sitio al inicio
  en iPhone, 512 = ícono de app / PWA).

LOGO COMPLETO PARA DOCUMENTOS, PRESENTACIONES, PRENSA
  png/lockup-light-2000.png   -> para fondos claros (documentos blancos, slides claros)
  png/lockup-dark-2000.png    -> para fondos oscuros (slides oscuros, video)
  Son PNG de máxima resolución, no se ven pixelados ni agrandados.

VISTA PREVIA AL COMPARTIR UN LINK (Twitter, LinkedIn, Slack, WhatsApp)
  png/social-banner-1200x630.png
  Este es el tamaño exacto que usan la mayoría de las plataformas para la
  miniatura de un link. Dáselo al desarrollador para el meta-tag "og:image".

SOLO EL ÍCONO (sin el texto "NIRIUM"), fondo transparente
  png/icon-transparent-512.png, -1024.png, -2048.png
  Para ponerlo sobre cualquier color de fondo sin que se vea un cuadro blanco
  o negro alrededor. Usa el de mayor resolución si vas a imprimir o agrandar.

VECTORIAL (SVG) — para diseñadores o desarrolladores
  svg/icon.svg              -> ícono a color, fondo claro
  svg/icon-on-dark.svg      -> ícono a color, fondo oscuro
  svg/icon-mono-dark.svg    -> ícono en un solo color negro (para imprenta,
                                grabado, o cualquier superficie de un color)
  svg/icon-mono-light.svg   -> ícono en un solo color blanco/crema
  svg/lockup-light.svg      -> ícono + palabra "NIRIUM" + lema, fondo claro
  svg/lockup-dark.svg       -> ícono + palabra "NIRIUM" + lema, fondo oscuro
  svg/favicon.svg           -> versión simplificada para el navegador
  Un archivo SVG se puede agrandar a cualquier tamaño sin perder calidad —
  úsalo siempre que el programa que estés usando lo acepte (la mayoría de
  editores de diseño y sitios web modernos sí).

NOTAS IMPORTANTES
  - La tipografía de la palabra "NIRIUM" en los lockups todavía usa una
    fuente de sistema (Arial) como placeholder — falta elegir una tipografía
    real antes de considerar esto una versión final de imprenta.
  - No existe todavía una versión de este pack probada contra el ancho real
    de la barra de navegación de nirium.xyz — se probó la legibilidad del
    ícono a 16px de forma aislada, no en ese contexto específico.
  - Color de marca: dorado con degradado (#F5D57A -> #D4AF37 -> #8B6F2E)
    sobre negro (#0A0A0C). El degradado es intencional — no reemplazar por
    un dorado plano sin decisión explícita, es parte del tratamiento visual.
